**No uses** `raw.githubusercontent.com` ni el enlace de GitHub al archivo: sale el código fuente, no la página.

Commit actual (D3 pozas Garcipollera + calor El Arrebol): `6504fee` (18 ago 2026).

## Opción 1 — la más fiable (1 minuto)

1. En el móvil, abrid este archivo en GitHub:
   https://github.com/exxasens0/Dams-cli/blob/6504fee/ruta-camper-refugio-2026/guia-movil.html
2. Pulsad el botón **Download** (o los tres puntos → Download).
3. Abrid el archivo descargado con Chrome / Safari. Funciona sin internet después.

## Cómo comprobar que es la versión nueva

En D3 debe aparecer:
- `Pozas Garcipollera` como plan de tarde
- botones **El Arrebol → Pozas Garcipollera** y **El Arrebol → Puente San Miguel**
- aviso de **~36°C** en El Arrebol
- `Open-Meteo · 2026-08-15`

Si aún sale Ciudadela como plan principal de tarde (sin pozas): no es esta versión. Usad opción 1 o 3 con el commit `6504fee`.
